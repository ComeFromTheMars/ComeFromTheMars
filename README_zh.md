### 🎓 研究方向
我致力于通过数据驱动的方法优化教育公平与效率，目前的研究重点包括：
- 📊 **数据挖掘 (Data Mining)**: 挖掘学习过程中的潜在模式。
- 🧠 **知识追踪 (Knowledge Tracing)**: 建模学习者的知识状态演变。
- 🏫 **智能教育 (Intelligent Education)**: 构建 AI 驱动的教学辅助系统。
- 🎯 **计算机自适应测评 (CAT)**: 实现精准、个性化的能力评估。
